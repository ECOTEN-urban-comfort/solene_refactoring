enum cs_parameter_error_behavior_t

Parameter check behavior when an error is detected

Enumerator
CS_WARNING 

Warn only

CS_ABORT_DELAYED 

Abort when cs_parameters_error_barrier is called.

CS_ABORT_IMMEDIATE 

Abort immediately
