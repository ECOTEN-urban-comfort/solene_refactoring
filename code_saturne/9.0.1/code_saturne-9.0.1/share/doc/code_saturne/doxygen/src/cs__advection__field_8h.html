◆ cs_advection_field_status_bit_t

enum cs_advection_field_status_bit_t

Bit values for specifying the definition/behavior of an advection field.

Enumerator
CS_ADVECTION_FIELD_NAVSTO 

Advection field stemming from the velocity in the (Navier-)Stokes system

CS_ADVECTION_FIELD_GWF 

Advection field stemming from the "GroundWater Flows" module. This is the Darcean flux.

CS_ADVECTION_FIELD_USER 

User-defined advection field.

CS_ADVECTION_FIELD_TYPE_VELOCITY_VECTOR 

The advection field stands for a velocity. This is described by a vector-valued array or function.

CS_ADVECTION_FIELD_TYPE_SCALAR_FLUX 

The advection field stands for a flux. This is described by a scalar-valued array or function.

CS_ADVECTION_FIELD_STEADY 

Advection field is steady-state

CS_ADVECTION_FIELD_LEGACY_FV 

Advection field shared with the legacy Finite Volume solver

CS_ADVECTION_FIELD_DEFINE_AT_VERTICES 

Define a field structure related to the advection field at vertices Post-processing and log operations are automatically activated.

CS_ADVECTION_FIELD_DEFINE_AT_BOUNDARY_FACES 

Define a field structure related to the advection field at boundary faces Post-processing and log operations are automatically activated.
