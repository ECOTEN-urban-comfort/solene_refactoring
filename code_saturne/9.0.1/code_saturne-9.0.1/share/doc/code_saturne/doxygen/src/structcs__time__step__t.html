Detailed Description

time step descriptor

Members of this time step are publicly accessible, to allow for concise syntax, as it is expected to be used in many places.

◆ dt_ref

dt_ref

Reference time step.
This is the time step value used in the case of a calculation run with a uniform and constant time step, i.e. idtvar =CS_TIME_STEP_CONSTANT (restart calculation or not). It is the value used to initialize the time step in the case of an initial calculation run with a non-constant time step (idtvar=CS_TIME_STEP_ADAPTATIVE or CS_TIME_STEP_LOCAL). It is also the value used to initialise the time step in the case of a restart calculation in which the type of time step has been changed (for instance, idtvar=CS_TIME_STEP_ADAPTATIVE in the new calculation and idtvar = CS_TIME_STEP_CONSTANT or CS_STEP_LOCAL_TIME in the previous calculation).
See Time step modification for examples.

nt_prev

Absolute time step number for previous calculation. In the case of a restart calculation, nt_prev is read from the restart file. Otherwise, it is initialised to 0 nt_prev is initialised automatically by the code, its value is not to be modified by the user.

◆ t_cur

t_cur

Current absolute time. For the restart calculations, t_cur takes into account the physical time of the previous calculations.
If the time step is uniform (idtvar = CS_TIME_STEP_CONSTANT or CS_ADAPTATIVE_TIME_STEP), t_cur increases of dt (value of the time step) at each iteration. If the time step is non-uniform (idtvar=CS_TIME_STEP_LOCAL), t_cur increases of dt_ref at each time step.
t_cur is initialised and updated automatically by the code, its value is not to be modified by the user.
